# Oportunidades e editais

Tipos: estágio, bolsa, IC, extensão, edital, intercâmbio, competição, evento, trainee, P&D e programa externo.

Campos: título PT/EN quando público, organização, tipo, prazo/timezone, link oficial, benefício/valor com fonte, elegibilidade, projetos relacionados, responsável, status, observações internas, visibilidade e data de verificação.

Estados: Mapeada → Em análise → Preparação → Submetida → Aprovada/Não aprovada; Encerrada. Para oportunidades informativas sem candidatura institucional, usar Aberta/Encerrada/Cancelada.

## Utilidade recorrente

Filtros salvos, prazos, elegibilidade clara, fonte oficial, itens relacionados e preferências de notificação. Não republicar dados obsoletos; job/rotina marca prazo encerrado, mas responsável confirma exceções.

## Aceite

Timezone explícito; link validado; nenhuma oportunidade vencida aparece como aberta; acesso a proposta/anexos respeita projeto; alerta deduplicado; ausência de resultados apresenta estado útil.
